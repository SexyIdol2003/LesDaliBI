Доработать витрину путевых листов для DataLens так, чтобы виды агроработ отображались читаемыми наименованиями из 1С, а не техническими UUID. Продолжить доработку исходного дашборда «Полевые работы» / «Работа сельхозтехники».

## Выполнено в DWH

### Справочник видов работ

Добавлен DAG `files/airflow/dags/dag_extract_work_types.py` для выгрузки и загрузки справочника технологических операций из 1С в таблицу `raw.r1c_tech_operations`.

### View для DataLens

Добавлен SQL-скрипт `files/13_update_putevoy_datalens_work_types.sql`, который обновляет view `mart.v_putevoy_rabota_datalens`.

Сохранён исходный порядок ранее существовавших колонок, поэтому обновление совместимо с уже созданным dataset DataLens. В конец view добавлены поля:

| Поле | Назначение |
|---|---|
| `operation_name` | Читаемое наименование вида работы из 1С |
| `operation_code` | Код операции |
| `operation_group_id` | Технический ID родительской группы операции |
| `operation_group` | Читаемое наименование группы операций |

View связывает факт путевых листов с `raw.r1c_tech_operations` по `agr_operaciya_id`, а родительскую группу получает повторным join к этому же справочнику.

### Проверка

Проверочный запрос по `mart.v_putevoy_rabota_datalens` успешно вернул группировки операций, названия, коды, суммарную площадь работ и число строк. Среди крупнейших операций по объёму: опрыскивание, внесение удобрений, тяжёлое дискование, дискование, вспашка, посев, культивация, посадка и уборка картофеля.

В данных используются две видимые группы исторического справочника: `Архив` и `Основная почвообработка`. Группу `Архив` нельзя исключать по умолчанию, поскольку она содержит существенный исторический объём работ.

## DataLens: доработка дашборда «Полевые работы»

Исходный дашборд ранее был собран без расшифрованных видов работ. Теперь в dataset необходимо обновить схему полей и заменить использование `operation_id` в существующих чартах на `operation_name`.

Рекомендуемые настройки и правки:

| Элемент | Настройка |
|---|---|
| Топ видов работ | Линейчатая диаграмма; измерение `operation_name`; показатель `SUM(work_area_ha)`; сортировка по убыванию; top-15 |
| Динамика по группам | Столбчатая диаграмма; X: `month`; Y: `SUM(work_area_ha)`; цвет: `operation_group`; при наличии включить накопление |
| Структура по группам | Кольцевая диаграмма; сектор: `operation_group`; показатель: `SUM(work_area_ha)` |
| Детальная таблица | Дата, документ, техника, сотрудник, группа операции, вид работы, код операции, гектары, выполнение нормы |
| Фильтры | Период, техника, исполнитель, тип техники, группа работ и вид работы |

Поле `operation_id` остаётся техническим идентификатором для сверки с 1С, но не должно быть основным полем визуализаций.
