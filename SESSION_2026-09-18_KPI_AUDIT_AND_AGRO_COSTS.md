Провести фактический аудит готовности ключевых BI-показателей «Лесные Дали» и определить, какие из них можно использовать в DataLens, какие требуют доработки, а какие блокируются источниками или качеством данных.

5. Затраты на каждую единицу техники за выбранный период.

## 6. KPI: план-факт ГСМ по операциям

### Найденные витрины

```text
mart.fact_fuel_norm_variance
mart.fact_fuel_plan_fact_by_operation
mart.fact_fuel_plan_fact_by_operation_reliable
```

### Норматив ГСМ

Норматив существует в данных путевых листов:

```text
raw.r1c_putevoy_list_lines.normativny_raskhod_gsm
```

То есть отдельный документ «План ГСМ» не обязателен для получения норматива в первой версии модели.

Норматив агрегируется в разрезе:

```text
месяц → техника → агрооперация
```

### Найденные бизнес-операции

В данных есть нужные группы, но их названия необходимо нормализовать:

```text
Вспашка
Вспашка (без характеристик)

Опрыскивание
Опрыскивание (без характеристик)

Грядообразование (без характеристик)
Грядообразование/гребнеобразование
Гребне-, Грядообразование, Фрезерование
```

### Критическое ограничение фактического ГСМ

Витрина `mart.fact_fuel_plan_fact_by_operation` НЕ получает фактическое топливо непосредственно на уровне операции.

Факт рассчитывается как пропорциональная аллокация месячного списания ГСМ техники:

```sql
fuel_allocated_liters =
    monthly_fuel_writeoff
    * hectares_op
    / hectares_total
```

Следствие:

```text
Факт л/га для одной техники в одном месяце
становится одинаковым для всех её операций.
```

Это расчётное распределение, а не прямой фактический расход конкретно на вспашку, гребнеобразование или опрыскивание.

### Выявленные проблемы

1. В августе 2026 есть строки с нормативом и площадью, но без факта топлива:

```text
2026-08, вспашка:
- площадь 196.15 га;
- факт 0 л;
- норма 1 924.90 л.

2026-08, опрыскивание:
- площадь 2 027.61 га;
- факт 0 л;
- норма 8 928.66 л.
```

2. Такие строки получают `reliability_flag = 'OK'`, так как флаг проверяет в основном наличие площади и число строк работ, но не наличие топлива.

3. Существуют большие отклонения, которые требуют подтверждения:
   - июль 2026, опрыскивание: факт 0.680 л/га при норме 4.634 л/га;
   - июнь 2026, опрыскивание: факт 0.829 л/га при норме 6.000 л/га;
   - апрель 2024, вспашка: факт 23.457 л/га при норме 0.034 л/га.

### Решение

Не публиковать текущую витрину как:

```text
«Фактический расход ГСМ по операции»
```

Допустимое временное название, если понадобится показать модель:

```text
«Расчётное распределение списанного ГСМ по операциям»
```

### Ожидание ответа сотрудницы

Пользователь написал сотруднице по поводу источника плана / норм ГСМ в 1С.

Нужно уточнить:

```text
1. Где в 1С хранится норматив ГСМ для операции?
2. Есть ли отдельный документ / регистр / технологическая карта?
3. Существует ли прямой источник:
   топливо → путевой лист → строка работы → операция?
4. Можно ли получить этот источник через OData?
5. От чего зависит норма:
   техника, операция, агрегат, культура, поле, сезон?
```

## 8. Текущий статус KPI

| KPI | Статус | Условие использования / блокер |
|---|---|---|
| Урожайность поле–сорт, т/га | Готов | Использовать фильтр `yield_t_ha IS NOT NULL AND area_ha > 0`; сезоны 2022 и 2025 наиболее надёжны |

| Факт ГСМ по операции, л/га | Расчётный | Факт топлива распределяется пропорционально площади, нет прямой привязки к операции |
| План-факт ГСМ по операции | Не принят | Норма есть, но факт не прямой; есть строки с нулевым фактом при заполненной норме |
| Затраты на технику, руб. | Частично готов | Не хватает исторических цен ГСМ, ремонт пока не подключён |
| Себестоимость 1 га за сезон | Не готов | Требуется согласованное включение ГСМ, техники, ремонтов, труда и агровходов |

## 9. Рекомендованный следующий порядок работ

### Приоритет 1. Зафиксировать и подключить DataLens

Подключить к DataLens готовые витрины:

```text
mart.v_fact_harvest_yield_by_variety
mart.v_agro_input_cost_per_field_season
```

Для урожайности использовать фильтр качества:

```sql
yield_t_ha IS NOT NULL
AND area_ha > 0
```

### Приоритет 2. Получить ответ по ГСМ

Дождаться ответа сотрудницы об источнике нормативов и факта ГСМ в 1С.

Нужен источник, позволяющий получить непосредственную связь:

```text
топливо
→ путевой лист
→ строка работы
→ операция
→ поле
→ площадь
```

Без этого нельзя назвать пооперационный расход ГСМ «фактом».

### Приоритет 3. Загрузить цены ГСМ

Использовать созданные экспортёры поступлений топлива / закупок для загрузки исторических цен.

Цель:

```text
заполнить mart.dim_fuel_price_monthly
→ пересчитать стоимость ГСМ по технике
→ получить затраты на технику за период
```

### Приоритет 4. Подключить ремонты

Проверить и включить в итоговую витрину:

```text
mart.fact_equipment_repair_cost
```

### Приоритет 5. Собрать себестоимость 1 га

Создать отдельную итоговую витрину, например:

```text
mart.v_field_cost_per_ha_by_season
```

Планируемые компоненты:

```text
подтверждённые СЗР;
подтверждённые удобрения;
стоимость ГСМ;
затраты на технику;
ремонт техники;
производственная зарплата;
семена — после проверки источника и классификации.
```

Нельзя публиковать полную себестоимость до заполнения цен ГСМ и определения корректного правила распределения затрат техники по полям.
