# LesDaliBI — сессия 2026-09-25

## Цель сессии

Довести KPI №6 по прямым затратам поля за сезон до единой, доступной DataLens витрины за 2022–2026 годы, не маскируя пробелы в исходных документах и ценах.

Целевая гранулярность:

- поле × сезон;
- текущая методика использует актуальный `mart.dim_field` для расшифровки поля;
- расчёт ведётся по экономической площади поля, когда она подтверждена и стабильна внутри сезона.

Целевой состав прямых затрат:

1. Труд полевых работ.
2. ГСМ: распределённые на поля фактические литры и оценка по закупочной цене.
3. Семена.
4. Удобрения.
5. СЗР.

В ходе сессии был закреплён принцип: отсутствие цены, классификации, источника или площади не заменяется нулём и не объявляется полной себестоимостью. Такие случаи остаются отдельными статусами и, при наличии прозрачного допущения, выводятся только как сценарные оценки.

## Опубликованные объекты

### Основной KPI №6

Опубликена и доступна роли `datalens_ro` витрина:

```sql
mart.v_field_season_kpi6_direct_cost
```

Гранулярность: `field_sk × season_year`.

В витрине доступны:

- идентификатор и название поля: `field_sk`, `pole_id`, `field_name`;
- год сезона: `season_year`;
- труд: `labor_rows`, `labor_rub`, `labor_rows_without_amount`;
- проверка площади: `min_economic_area_ha`, `max_economic_area_ha`, `labor_rows_without_area`, `stable_economic_area_ha`;
- ГСМ: `fuel_rows`, `allocated_fuel_liters`, `covered_fuel_rub_no_vat`, `fuel_rows_without_exact_price`, `fuel_rows_not_reconciled`;
- агровходы: строки и суммы по семенам, удобрениям и СЗР;
- контрольные поля агровходов: `agro_rows_without_strict_price`, `other_agro_rows`;
- частичная зарегистрированная оценка: `partial_estimated_direct_cost_rub` и `partial_estimated_direct_cost_rub_per_ha`;
- строгая покрытая зарегистрированная оценка: `covered_registered_direct_cost_rub` и `covered_registered_direct_cost_rub_per_ha`;
- итоговый статус качества: `coverage_status`;
- методическая пометка: `method_note`.

Статус `COVERED_REGISTERED_DIRECT_COST_ESTIMATE` означает только следующее:

- у поля есть строки труда и ГСМ;
- в труде нет строк без денежной суммы;
- все учтённые топливные строки имеют точную цену закупки той же марки за тот же месяц и сверены;
- в зарегистрированных агровходах нет строк без строгой цены;
- нет неклассифицированных агровходов вне категорий `SEEDS`, `FERTILIZERS`, `CROP_PROTECTION`;
- экономическая площадь положительна и стабильна внутри сезона.

Этот статус не означает, что подтверждена полная фактическая себестоимость производства: он отражает покрытие зарегистрированных прямых затрат в доступных источниках и в рамках текущей методики.

### Сценарий ГСМ

Создана и опубликована витрина:

```sql
mart.v_field_fuel_previous_month_scenario
```

Файл локального SQL-определения:

```text
files/64_mart_field_fuel_previous_month_scenario.sql
```

Назначение: отдельно оценивать стоимость списанного топлива, когда для той же марки отсутствует закупка в месяце списания, но есть подтверждённая закупка той же марки в непосредственно предыдущем календарном месяце.

Гранулярность сценария:

```text
поле × месяц × марка топлива
```

Метод:

```text
PREVIOUS_MONTH_PURCHASE_PRICE_ESTIMATE
```

Ключевые ограничения:

- сценарий использует только строки с `NO_EXACT_MONTH_BRAND_PRICE`;
- используется та же `fuel_brand_id`;
- цена берётся только за предыдущий календарный месяц;
- используется только подтверждённая точная закупочная цена предыдущего месяца;
- сценарий не меняет строгую цену текущего месяца;
- сценарная сумма не входит автоматически в строгий KPI №6.

### Сценарий агровходов

Создана и опубликована витрина:

```sql
mart.v_field_agro_later_price_scenario
```

Назначение: показывать отдельную сценарную оценку для фактических списаний семян, удобрений и СЗР, по которым цена закупки найдена только после даты списания.

Отбор сценарных строк:

```text
purchase_price_match_status = 'ONLY_PRICE_AFTER_WRITEOFF'
agro_cost_quality_status = 'PRICE_AFTER_WRITEOFF_NOT_IN_STRICT_COST'
strict_cost_rub_no_vat IS NULL
diagnostic_estimated_cost_rub_no_vat IS NOT NULL
```

Метод сценария:

```text
PURCHASE_PRICE_AFTER_WRITEOFF_ESTIMATE
```

Эта витрина читает уже рассчитанную `diagnostic_estimated_cost_rub_no_vat` из `mart.v_field_agro_input_cost_direct`. Новый повторный JOIN к закупкам не создаётся, поэтому не возникает риск размножения строк закупок.

### Единая витрина для DataLens

Создана и опубликована витрина:

```sql
mart.v_field_season_kpi6_with_scenarios
```

Гранулярность:

```text
поле × сезон
```

Назначение: единый источник DataLens, объединяющий текущий KPI №6 и две явные сценарные добавки, без изменения исходного строгого статуса покрытия.

Витрина включает:

- все ключевые поля `mart.v_field_season_kpi6_direct_cost`;
- строгие/частичные компоненты: труд, покрытая стоимость ГСМ, семена, удобрения, СЗР;
- `strict_components_partial_rub` — текущая частичная зарегистрированная оценка из KPI №6;
- `scenario_fuel_liters`, `scenario_fuel_rub_no_vat`, `scenario_fuel_rows`;
- `scenario_agro_rub_no_vat`, `scenario_agro_rows`;
- `partial_plus_scenarios_rub`;
- `partial_plus_scenarios_rub_per_ha`;
- `combined_method = 'PARTIAL_REGISTERED_COST_PLUS_EXPLICIT_PRICE_SCENARIOS'`.

Формула объединённого сценарного итога:

```text
partial_plus_scenarios_rub =
    strict_components_partial_rub
  + scenario_fuel_rub_no_vat
  + scenario_agro_rub_no_vat
```

Важно: `partial_plus_scenarios_rub` и `partial_plus_scenarios_rub_per_ha` являются частичной сценарной оценкой. Они не являются полной фактической себестоимостью и не должны заменять `coverage_status` или строгие показатели KPI №6.

### Выводы по причинам

1. Часть СЗР и удобрений имеет только цену закупки после списания. Они не входят в строгую стоимость, но включены в отдельный агросценарий.
2. Собственные семена имеют статус `OWN_SEED_COST_NOT_AVAILABLE_IN_EXTRACT`. Для них в текущей выгрузке нет себестоимости собственного семенного материала. Их нельзя оценивать ценой других покупных семян.
3. Часть покупных семян имеет закупки по той же номенклатуре, но различается характеристика товара. Полный ключ товарной строки включает характеристику и/или серию, поэтому снятие этого ограничения без подтверждённого маппинга может неверно назначить цену.
4. Отдельные строки 2025 года имеют статус `DO_NOT_USE_REVIEW_REQUIRED` и номенклатуры с названием `(не использовать)`. Несмотря на наличие закупочной цены, они намеренно не входят в строгую стоимость до предметной проверки в 1С.
5. Для старой обобщённой номенклатуры `Семена картофеля` за 2022–2024 годы закупок по тому же точному `nomenklatura_id` не найдено. Нужен подтверждённый маппинг на фактические покупные номенклатуры либо отдельный источник стоимости.

## Использование в DataLens

Рекомендуемый основной источник для итогового дашборда:

```sql
mart.v_field_season_kpi6_with_scenarios
```

Поля и подписи для показа:

| Поле | Рекомендуемая подпись | Интерпретация |
|---|---|---|
| `covered_registered_direct_cost_rub` | Покрытые зарегистрированные прямые затраты, ₽ | Показывать как строгую оценку только для строк с покрывающим статусом |
| `covered_registered_direct_cost_rub_per_ha` | Покрытые зарегистрированные прямые затраты, ₽/га | Строгий показатель на экономический гектар |
| `strict_components_partial_rub` | Частичная зарегистрированная оценка, ₽ | Может не включать строки с пробелами цены/классификации |
| `scenario_fuel_rub_no_vat` | ГСМ — сценарий по закупке предыдущего месяца, ₽ | Отдельная явная оценка |
| `scenario_agro_rub_no_vat` | Агровходы — сценарий по закупке после списания, ₽ | Отдельная явная оценка |
| `partial_plus_scenarios_rub` | Частичная оценка с ценовыми сценариями, ₽ | Не называть полной себестоимостью |
| `partial_plus_scenarios_rub_per_ha` | Частичная оценка с ценовыми сценариями, ₽/га | Не называть полной себестоимостью на гектар |
| `coverage_status` | Статус покрытия | Обязательный фильтр/разрез качества |
| `combined_method` | Метод объединённой оценки | Техническая и методологическая маркировка |

Не следует:

- переименовывать `partial_plus_scenarios_*` в «фактическую себестоимость»;
- смешивать сценарные суммы со строгими без отдельной подписи;
- показывать нулевую стоимость там, где цена отсутствует;
- считать строку полностью покрытой только потому, что она получила сценарную сумму.

## Что осталось

1. Разобрать поля без источников труда/ГСМ. Отсутствие полевой строки не означает автоматически нулевой расход.
2. Восстановить или утвердить метод площади для полей с `NO_STABLE_ECONOMIC_AREA`.
3. Получить себестоимость собственных семян или источник учёта выпуска/перемещения семенного материала.
4. Проверить в 1С смысл и правила использования номенклатур `(не использовать)`.
5. Подтвердить соответствие характеристик покупных семян в документах закупки и списания либо создать управляемую таблицу маппинга.
6. Для `Семена картофеля` 2022–2024 определить связку общей номенклатуры списания с конкретными номенклатурами закупки только после предметного подтверждения.
7. При необходимости расширить набор сценариев, но каждый новый метод должен иметь отдельный статус, QA и не менять строгую стоимость задним числом.

3. Создать недостающий файл с финальным SQL объединённых сценариев.
