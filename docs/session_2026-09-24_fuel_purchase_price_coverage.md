# LesDaliBI — оценка списанного дизеля по закупочной цене месяца

- **Дата сессии:** 2026-09-24
- **Репозиторий:** `SexyIdol2003/LesDaliBI`
- **SQL-коммит:** `fd04736 feat(dwh): add exact purchase price fuel coverage mart`
- **Статус:** витрины созданы, применены в PostgreSQL и проверены QA.

## Цель

Построить прозрачную расчётную оценку стоимости списанного дизельного топлива, не подменяя её первичной фактической стоимостью списания.

Задача возникла после проверки текущей `mart.dim_fuel_price_monthly`: в ней было только две подтверждённые цены, поэтому покрытие фактических литров составляло:

| Год | Покрытие подтверждённой ценой |
|---:|---:|
| 2021 | 0,00% |
| 2022 | 0,00% |
| 2023 | 0,00% |
| 2024 | 0,00% |
| 2025 | 22,07% |
| 2026 | 32,30% |

Вместо молчаливого распространения двух цен был найден более строгий источник: закупки той же номенклатуры топлива в том же месяце.

## Источники

Фактические литры списания:

```sql
mart.fact_fuel_writeoff
```

Закупки топлива:

```sql
mart.v_fuel_purchase_by_month
```

Классификация закупочной номенклатуры:

```sql
raw.v_purchase_nomenclature_classification
```

Ключ сопоставления:

```text
period_month = purchase_month
fuel_brand_id = nomenklatura_id
```

Сопоставление по UUID подтверждено для всех марок из фактического списания:

| Марка списания | Период | Литры списания | Статус |
|---|---|---:|---|
| Дизельное топливо вид III, кл. С | 2021-07—2023-05 | 190 369,89 л | Точное UUID-сопоставление |
| Дизельное топливо Евро сорт С | 2023-05—2026-08 | 446 500,23 л | Точное UUID-сопоставление |
| Дизельное топливо ЭКТО | 2024-05 | 600,00 л | Точное UUID-сопоставление |

Все три марки классифицированы как:

```text
fuel_kind = diesel
```

Текстовое сопоставление по названию не используется.

## Методика

Для каждой строки:

```text
месяц × марка дизельного топлива
```

расчёт выполняется только при наличии закупки той же номенклатуры в том же месяце:

```text
purchase_price_without_vat_rub_per_liter =
SUM(закупка без НДС, ₽)
/
SUM(закупленное количество, л)
```

```text
estimated_covered_fuel_cost_without_vat_rub =
writeoff_liters
× purchase_price_without_vat_rub_per_liter
```

Дополнительно формируется оценка с НДС:

```text
estimated_covered_fuel_cost_with_vat_rub
```

Если в месяце нет закупки той же номенклатуры:

```text
purchase_price_status =
NO_EXACT_MONTH_BRAND_PURCHASE_PRICE
```

При этом:

```text
цена = NULL
расчётная стоимость = NULL
```

Не применяются:

- цена предыдущего месяца;
- цена следующего месяца;
- цена другой марки дизеля;
- средняя годовая цена;
- общая цена по категории `diesel`;
- ручная дооценка без отдельного утверждённого правила.

```text

Расчётная стоимость списанного дизеля по закупочной цене месяца, с НДС

Литры списанного дизеля без точной закупочной цены
Покрытие списанных литров точной закупочной ценой, %
```

Для итогового показателя покрытия использовать:

```sql
SUM(writeoff_liters) FILTER (WHERE has_exact_purchase_price)
/
NULLIF(SUM(writeoff_liters), 0)
```

или эквивалентную формулу DataLens.

Для стоимости использовать только:

```sql
SUM(estimated_covered_fuel_cost_without_vat_rub)
```

и обязательно показывать рядом:

```text
price_coverage_pct
price_coverage_status
price_method
```

## Что нельзя публиковать

Пока нельзя использовать:

```text
Фактическая стоимость списания ГСМ
Полная стоимость дизеля
Полная стоимость ГСМ по сезону
Полная себестоимость топлива на гектар
Полная себестоимость 1 га
```

Причины:

1. Закупочная цена является расчётной оценкой, а не первичной стоимостью конкретного списания.
2. В 2022–2026 присутствуют месяцы без закупки той же номенклатуры.
3. Минимальное покрытие составляет 82,24% в 2024 году.
4. Витрина покрывает текущие дизельные марки списания, но не является универсальной моделью всех видов топлива и масел.
5. Нет утверждённой методики распределения стоимости топлива по полям, контурам и культурам.

## Связь с другими витринами

Витрина может использоваться как отдельный ценовой слой для анализа затрат на технику, но не заменяет:

```sql
mart.dim_fuel_price_monthly
```

`mart.dim_fuel_price_monthly` содержит отдельные подтверждённые учётные цены из отчётов 1С. Новая витрина использует расчётную закупочную цену и хранит отдельный метод/статус качества.


## Следующие шаги

1. Отдельно определить правила, при которых расчётная закупочная цена может использоваться в витрине учтённых затрат на технику.
2. Не смешивать `PURCHASE_PRICE_EXACT_MONTH_BRAND` с подтверждёнными учётными ценами без признака метода.
3. Проверить возможность связать расходы дизеля по технике с полевыми работами и экономической площадью на дату.
4. Восстановить первичные документы или регистр стоимости для месяцев без точной закупочной цены.
5. Найти подтверждённый источник ремонтов техники.
6. Не строить полную себестоимость 1 га до утверждения общей методики распределения и статусов полноты.
