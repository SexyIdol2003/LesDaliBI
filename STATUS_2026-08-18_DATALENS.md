## Созданные чарты

На дашборд добавлены 6 чартов:

1. **Валовой сбор по годам, т** — столбчатая диаграмма с суммой `kolichestvo_t` в разрезе `god_urozhaya`.
2. **Урожай по полям, т** — диаграмма с суммой `kolichestvo_t` в разрезе `pole_nomer`.
3. **Урожай 2025: полив и без полива, т** — столбчатая диаграмма по полю `poliv`, отфильтрованная на `god_urozhaya = 2025`.
4. **Урожай картофеля по сортам, т — 2025** — столбчатая диаграмма с суммой `kolichestvo_t` в разрезе `sort`, отфильтрованная на `god_urozhaya = 2025`.
5. **Урожай 2025 по полям и участкам** — таблица с полями `pole_nomer`, `uchastok_nomer`, `sort`, `reproduktsiya`, `poliv`, `kolichestvo_t`; фильтр: `god_urozhaya = 2025`.
6. **Динамика урожая по месяцам** — линейная диаграмма суммы `kolichestvo_t` по `doc_date` с группировкой по месяцам.

## Настройки, которые подтвердили работу

- Текстовые поля (`sort`, `pole_nomer`, `uchastok_nomer`, `reproduktsiya`, `poliv`) используются без агрегации.
- Количественное поле `kolichestvo_t` используется с агрегацией **Сумма**.
- Поле `god_urozhaya` в фильтрах используется без агрегации; для детализации 2025 года применяется условие `Равно 2025`.
- После создания чистого чарта без ошибочных вычислений визуализации начали строиться корректно.
